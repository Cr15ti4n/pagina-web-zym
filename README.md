# Grupo Z&M — Sitio Web

Sitio web corporativo de **Grupo Z&M**, empresa con más de 21 años desarrollando infraestructura para los sectores de hospitalidad, retail e industria en México.

## Tecnologías

- HTML5 (single-page)
- CSS3 con variables y animaciones
- JavaScript vanilla
- Imágenes optimizadas en formato WebP

## Visualización

Abrir `index.html` en cualquier navegador o desplegar en cualquier servidor web estático.
